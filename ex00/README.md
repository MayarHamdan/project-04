# Mayar Hamdan — Personal Portfolio

## About the Project

This project is a responsive personal portfolio created to introduce
myself, showcase my skills, present my learning projects, and provide
contact information.

The portfolio focuses on my interests in Cybersecurity, Information
Security, Governance, Risk and Compliance (GRC), and Web Development.

## Features

- Personal introduction and profile picture.
- Downloadable CV.
- Skills section covering cybersecurity and web development fundamentals.
- Projects section showcasing Projects 00–03.
- Hobbies and personal interests.
- Contact form with basic client-side validation.
- Dark and light theme switcher.
- Theme preference saved using localStorage.
- Responsive layout for desktop, tablet, and mobile screens.

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- Flexbox
- CSS Grid
- CSS Media Queries
- DOM Manipulation
- Event Handling
- localStorage
- Git and GitHub
